# 失败路径与被证伪的假说

发布模型通常只写成功的部分。这份文档记录**全部走不通的路**，
以及**方法上踩过的坑**，用于避免重复投入。所有否定结论均有配对检验或明确机制。

---

## 一、知识层：十一条无效路径

底座 0.5964，最终 0.6445。中间试过的方案里，**只有两条有效**。

### 有效的两条

| 方案 | 效果 | 检验 |
|---|---|---|
| 偏好靶向训练（MolSkill 去重后 4,275 对真实标注，1 轮） | preference 0.5800→0.6620 | p=8.9e-08 |
| Python 工具执行（数值题写代码） | 数值题 0.4362→0.6214 | p<1e-4 |

### 无效的九条

| 方案 | 规模 | 结果 | 检验 |
|---|---|---|---|
| 通用语料 CPT | 12.5 万文档 | 0.5896 | p=0.10 |
| 通用语料 SFT | 98.9 万条 | 0.6011 | p=0.46 |
| CPT→SFT 串联 | — | 0.5968 | p=1.00 |
| 配平采样 SFT | 194 万条 | 0.5914 | p=0.15 |
| 扩量 SFT（8×） | — | 0.5978 | p=0.78 |
| 原生思考模式 | `enable_thinking=True` | 0.5260 | **p=3e-24，显著变差 7.0pp** |
| 推理链训练 | 2 万条真 R1 推理链 | 0.5878 | p=0.07 |
| 偏好蒸馏（目标类别） | 4 万对 | preference −1.2pp | p=0.45 |
| 基数训练 | 1.96 万条 GHS 派生 | ChemComp 零变化 | — |

### 推理侧四种裁剪法，全部不如什么都不做

多选题上模型系统性过度多选（394 道多答案题里 45.2% 选多了，gold 从不超过 3 个）。
理论裁准上限 +6.9pp，实际：

| 方法 | 效果 |
|---|---|
| 固定阈值 P(yes)>0.5 | −1.18pp |
| 模型自报基数取 top-N | −0.22pp（基数准确率仅 6.1%，几乎总答"4"） |
| N = round(ΣP) | −1.04pp |
| N = count(P>均值) | −1.97pp |
| **不裁** | **±0.00pp（最优）** |
| oracle 基数（看答案，上界） | +2.41pp |

**为什么够不着**：裁剪代价不对称。裁对赚 1 题、裁错赔 1 题，而 stage-1 本来就有 25% 是对的，
任何误裁先砸掉这部分。基数准确率要远高于 30% 才可能翻正。

## 二、两个被证伪的机制假说

发现偏好蒸馏数据在**非目标类别**上显著提升后，提出了两个机制假说，**都被证伪**。

### 假说 1：有效成分是"分子曝光"

**观察**：4 万对偏好蒸馏数据 → 目标类别 chemical_preference 零效果（p=0.34），
但 analytical_chemistry 翻对 10/翻错 1（p=0.0117）、organic 翻对 10/翻错 2（p=0.0386）。

**推断**：价值不在偏好标签（自训打分器仅 0.677 准确率，1/3 标签错），而在"读了 4 万对分子结构"。

**验证**：造 4 万条单分子结构题（RDKit 确定性标签，噪声为零，分子曝光量相同）。

**结果**：analytical **−6.58pp（p=0.013），方向反了**。假说证伪。

### 假说 2：有效成分是"成对比较任务形式"

**推断**：偏好题是两分子对比判断，结构题是单分子查表提取，可能是任务形式的差别。

**验证**：造 4 万条成对比较题（"A 和 B 哪个分子量更大"，RDKit 确定性标签）。

**结果**：analytical 仍 −3.29pp；与结构题差异 p=0.14，噪声内。假说证伪。

### 真实情况

三个版本（蒸馏 / 结构 / 成对）总分分别 0.6370 / 0.6359 / 0.6445，**彼此都是噪声内差异**。
收益分散在各类别，不集中在任何预测的地方。更像"多了几万条零噪声化学数据"的普遍性收益，
**没有可归因的特定机制**。

## 三、评测工具本身的三次翻车

同一类错误犯了三次，一次比一次隐蔽。

### ① 没量尺子

用来测条件遵循的 gap 打分器**从未被验证过**。实测它自己的误差：

```
MAE 1.698 eV，Spearman 0.405   （数据 std 1.88，直接输出均值的 MAE 1.389）
```

**尺子误差比被测对象还大。** 用它量了四轮训练约 10 小时，得出的结论全部作废：

| 曾报告 | 真实（重训尺子后，MAE 0.404） |
|---|---|
| v1 响应跨度 2.3 eV「原地打转」 | 跨度 11.12 eV，五个目标点全跟得上（偏差 ±0.3） |
| embedding 注入提升 25% | 提升 11% |
| 合法率 0.882 是「欠账」 | 0.992，没有欠账 |

### ② 切分方式错

电导率打分器随机切分 R² 0.8859，按文献切只剩 0.3085。
同一篇文献是同一批实验，随机切会让模型见过测试集的实验条件。

### ③ 只切了一次

**已经做对了"按文献切"，但只切了一次。** 单次 R² 0.7336，
5 折交叉验证 −0.03 / −inf / 0.14 / 0.29 / −0.20。

**规则**：分组数 < 30 时必须报 K 折交叉验证的均值±方差，不许报单次切分。
方差本身是结论的一部分。

## 四、MD 四轮试错

| 版本 | 现象 | 根因 |
|---|---|---|
| v1 | 73 分钟卡死，无任何进度输出 | 不知道死在哪 |
| v2 | 21 分钟后卡死，显存 56.6→72.6 GB、GPU 0%、CPU 单核满载 | 近邻表爆炸 |
| v3 | 压缩第 40 步立即报错 | **加了最小间距检查，5 分钟定位** |
| v4 | 全程稳定跑完 | **改用 RDKit 生成几何** |

**根因**：手写的分子坐标本身是错的（DMC 里两原子只差 0.707 Å），
弛豫压不干净，一压缩就撞。**分子几何必须用 RDKit EmbedMolecule + MMFF 生成。**

**关键调试经验**：受力是滞后指标，**最小原子间距是先行指标**。
原子撞到 0.46 Å 时受力还正常（3~4 eV/Å），等受力爆了近邻表已经炸了。

### MSD 分析的统计缺陷

三个温度点 α 检验全部失败，且分段出现**负值**（MSD 随时间下降，物理不可能）。
根因不是轨迹长度，是统计量：

- 只有 2 个 Li⁺ → 噪声压倒信号
- 只用 t=0 一个时间原点 → 5000 帧只贡献 1 条样本

**修复**：多时间原点滑动窗口 + 离子数加到 6。修复后 α=0.95，**20 ps 就进扩散区**
（之前 80 ps 都不行）。同样的轨迹，统计误差降一个数量级。

## 五、操作层面的坑

| 坑 | 犯了几次 | 后果 |
|---|---|---|
| 改了脚本没重启进程 | 2 | emb4 崩在第 1000 步；MD 白跑 96 分钟且轨迹没存 |
| 跨机同步覆盖本机独有补丁 | 1 | 多副本 SEED 补丁被冲掉，全部 NameError |
| 长任务无进度输出 | 2 | "正常运行"和"卡死"无法区分，两次误判 |
| `pkill -f` 匹配到自己的 SSH 命令行 | 3 | 连接被杀 |
| 断言阈值靠猜设绝对值 | 2 | 拦住了有效结果 |

**规则**：
- 打完补丁要么立刻重启，要么在日志里确认新代码的标志性输出出现
- 覆盖脚本前先 diff，或把补丁做成幂等脚本
- 超过 10 分钟的任务，进度打印间隔 ≤ 总时长的 1/20
- 用 `[p]attern` 括号技巧或显式 PID，不用 `pkill -f`
- 断言阈值按输入规模缩放，不写绝对值
