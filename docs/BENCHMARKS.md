## 1. 知识层：ChemBench

### 1.1 评测协议

- 题库：2,785 题（MCQ 2,542 + 数值题 243），来自 `lamalab-org/chembench`
- 计分：官方 `chembench.metrics.all_correct`
  - MCQ：`set(found) == set(gold)`，**集合完全相等**才得分
  - 数值题：`mae(found, expected) == 0`，**严格浮点相等**
- 抽不出答案计为错，不从分母剔除
- 生成：贪心解码，`enable_thinking=False`，`max_new_tokens=24`

## 3. 配方层：电导率

### 3.1 数据

CALiSol-23，13,825 条实验电导率，27 篇文献，14 种锂盐 × 38 种溶剂，温度 194–477 K。
清洗后 13,270 条（剔除 k≤0）。

**数据坑**：4 篇文献电导率中位数 <1 mS/cm（1M LiPF6 碳酸酯体系真值约 10），
S/m 与 mS/cm 混用，336 条，训练前应剔除。

### 3.2 泛化能力（关键限制）

必须按文献（doi）切分——同一篇是同一批实验、同一套设备，随机切会泄漏。

| 切分方式 | R² | 说明 |
|---|---|---|
| 随机切分 | 0.8859 | **假的**，同文献数据分散在两侧 |
| 按文献单次切分 | 0.7336 / 0.7511 | **抽签结果**，方差极大 |
| **按文献 5 折交叉验证** | **−0.03 / −inf / 0.14 / 0.29 / −0.20** | **真实泛化能力** |

汇总：Spearman 0.4088 ± 0.1305；MAE 1.27–2.39（输出均值基线 3.204，说明学到了东西，
但误差散布超过数据方差）。

**根因**：仅 23 篇文献，20% 测试集只有 4–5 篇，单次切分方差能让同一模型从 R² −0.04 跳到 0.75。
且跨文献本身就难——不同实验室的设备、纯度、测量方法差异，同配方能差 20–30%。

**结论**：分布内插值可信，外推到新溶剂体系不可信。

## 4. MLIP：MACE-OMol 在电解液上的可用性

### 4.1 静态性质（通过）

| 检验 | 结果 | 参考 |
|---|---|---|
| 元素覆盖 | 83 种，含 Li | MACE-OFF23 仅 10 元素、无 Li |
| Li–EC 结合能 | −2.419 eV | 文献 −2.0 ~ −2.5 eV |
| EC 的 C=O 键长 | 1.205 Å | 实验 1.19 Å |

### 4.2 动力学性质（不通过）

| 量 | MACE-OMol | 实验/文献 | 偏差 |
|---|---|---|---|
| 平衡密度（NPT, 298K） | 1.358 ± 0.020 g/cm³ | ~1.20 | **+14.3%** |
| Li⁺ 扩散系数 | 9.74e-10 cm²/s @436K | 2.5e-06 @298K | **慢约 2500 倍** |

扩散指数 α = 0.95（分段 0.81 → 0.90 → 0.95），确认在扩散区，测量本身可信（误差带 ±18%）。

**诊断**：势能面结合过强 → 液体过密 → 自由体积不足 → Li⁺ 跳不出溶剂笼。
静态量对、动力学错，符合文献记录的基础 MLIP 通病
（[arXiv:2510.05020](https://arxiv.org/pdf/2510.05020)：MACE-MPA-0 在 LiF 中活化能算对但扩散系数各温度全偏低）。

**诊断链（每步排除一个候选原因）：**
```
v1-v3 跑崩        根因：手写分子坐标错（DMC 里两原子只差 0.707 Å）
v4    跑通但 D 错  10 ps 不够
v5    HMR 加速     80 ps 仍不够，且 α 检验暴露 MSD 出现负斜率（物理不可能）
修统计 多时间原点   α=0.95 通过，20 ps 就够 —— 之前是统计缺陷不是轨迹长度
NPT   密度诊断     +14.3%，定位到势能面本身
```
**关键调试经验**：受力是滞后指标，**最小原子间距是先行指标**。
原子撞到 0.46 Å 时受力还正常（3~4 eV/Å），等受力爆了近邻表已经炸了。

**MSD 统计的两个坑**：只有 2 个 Li⁺ 且只用 t=0 一个时间原点，
会让 MSD 出现负斜率。改成多时间原点滑动窗口 + 6 个离子后，
同样轨迹的统计误差降一个数量级，20 ps 就能进扩散区。

**修复方向**：换 MACE-OMAT-0（含更多非平衡构型）或微调（文献称 300 个数据点即可显著改善）。
**筛选方法**：先测 NPT 平衡密度（30 分钟），|偏差| <5% 才值得投扩散测试（10 小时）。
密度对不上的模型，扩散一定也不对。
**明确排除**：加 D3 色散会更糟——色散是增加吸引力，而问题是吸引力已经过强。

### 4.4 排序分辨力实测（2026-09-02）

用同一体系、同一模型、只换随机种子跑两遍 1 ns：

```
          α判定    D (cm²/s)    电导率      
种子 0    通过     6.79e-07     6.81 mS/cm
种子 1    未过     3.70e-07     3.71 mS/cm
                  相差 1.84 倍
```

要区分的两个配方：EC:DMC 10.0 mS/cm vs PC 5.8 mS/cm，**差 1.72 倍**。

**自身波动大于要分辨的差距，因此单次运行不能用于配方排序。**

不做这个复现，就会拿种子 0 的「0.71×实验值」去宣称可用于筛选 ——
那个数是真的，但它是一次抽样，换个种子就是 0.37×。

原因是统计量太小：6 个 Li⁺、扩散区仅约 2.3 个独立时间原点，
逐离子 D 最快的是最慢的 5 倍。修法与代价：

```
多种子取平均    每配方 5~8 个种子      ×5~8
加大体系        离子数 6 → 24~32      ×4~8
→ 一个配方需 17~27 小时才能给出可比较的数
```
