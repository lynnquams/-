# 计划：让模型真正会调计算软件

## 目标

不是让模型背化学知识，是让它**听懂需求 → 选对工具 → 给对参数 → 读懂结果 → 决定下一步**。
软件范围：ABACUS、LAMMPS、QE、xTB。

## 为什么先做脚手架再改权重

三个独立来源指向同一结论，改脚手架的增益是改权重的 3~4 倍：

```
MDAgent2 (2026-01)   微调本身 14.23%   放进运行时循环 37.95%
FoamGPT vs Foam-Agent 微调 7B 22.73    未微调的 agent 脚手架 88.2
Purdue LAMMPS 研究    裸生成 46%        校验做成 skill 后 5/6 全对
```

我们自己的实测同向：

```
Python 工具层   +1.22pp   p < 1e-4     显著
DPO 改权重      +0.36pp   p = 0.378    噪声
```

**且必须做 weights-vs-scaffold 消融**，否则涨了也说不清是谁涨的。

| 来源 | 规模 | 状态 |
| --- | --- | --- |
| ABACUS 官方套件配对 | 629 条（含 16 个失败样本） | ✅ |
| ABACUS 硬任务 | 326 个（EOS/弹性/缺陷/表面/吸附） | 🔄 |
| Li₃OCl NEB | 100 个镜像，7 条路径，能垒 0.454~0.652 eV | ✅ |
| LAMMPS 官方算例 | 809 个，644 个带官方参考值 | 🔄 |
| xTB 团簇/脱溶剂化 | 108 + 30，均已验对文献 | ✅ |

**开训门槛**：上述 🔄 全部跑完，且每类都有「输入 + 执行结果 + 失败样本」三件套。
失败样本尤其重要 —— 文献确认化学领域没有把输入与执行结果配对的公开数据集
（两个可下载的都是 CFD 的 NL2FOAM / FoamGPT），纠错轨迹是唯一空白。

## 四步

### 第一步 · 工具层（不训练）

AbacusCopilot 已装并测通，它是确定性的 CLI，输入文件的正确性由它保证：

```
101 SCF · 102 relax · 103 MD · 104 能带 · 105 DOS · 106 功函数
107 ecutwfc 扫描 · 108 kspacing 扫描 · 109 收敛分析
110 EOS · 111 弹性 · 112/113 声子 · 201 CIF→STRU · 202 POSCAR→STRU
```

模型的任务因此从「逐 token 写 INPUT」变成「选任务号 + 给参数」，可靠得多。

### 第二步 · 闭环（评测基准）

```
自然语言任务 → 模型选工具/参数 → 校验器 → 真跑引擎 → 比对参考值
```

三件已就绪：
- `clearchem/compchem/validate_abacus.py` 规则来自官方文档，含 AbacusCopilot 输出回归
- `clearchem/compchem/run_abacus.py` 执行器，官方算例复现到 6.8e-09 eV
- `clearchem/compchem/hard_queue.py` 难度排序 + 资源调度

**判据分三级**：① 跑通 ② 结果自洽（SCF 收敛、无 NaN）③ 数值落在参考容差内。
第三级才是真本事。

### 第三步 · 消融（先做，再决定训不训）

| 组 | 配置 | 目的 |
| --- | --- | --- |
| A | 裸底座 + 工具层 + 校验器 | 脚手架能到多少 |
| B | A + 少样本示例 | 提示工程的上限 |
| C | B + 微调权重 | 权重还值多少 |

**若 C − B < 基准的最小可分辨差，就不训**。这条是硬的：
ChemBench 上 DPO 的 +0.36pp 就死在这条判据上。

### 第四步 · 训练（仅当第三步显示有空间）

- 数据：上表全部，按许可分标（LGPL 的 375 条可一键排除）
- 目标：任务 → 工具调用序列，不是任务 → 输入文件全文
- 切分：**按体系与技能切分**，训练集不得见过测试集的同类计算，否则测的是记忆

## 红线

- ChemBench 测不了这件事：`technical_chemistry` 只有 40 题，全对也只 +0.47pp，
  低于最小可分辨差 1.15pp。**必须用自建基准，不能拿 ChemBench 充数。**
- 任何数值先问"合不合物理"，再问"跑通没有"。今天三个方法错误全是这样抓出来的：
  MD 手写坐标撞到 0.707 Å、团簇不优化 15% 结合能为正、脱溶剂化拉单原子算出 3~7 eV。
- 容器资源读数不可信：nproc 报 48 真实 18、free 报 251G 真实 90G，一律查 cgroup。
- 任何长任务开跑前先验依赖 —— a800 上 5.4 小时的 MD 跑满 250,000 步后倒在
  `ModuleNotFoundError: No module named 'msd_ana'`，靠存了轨迹才没白跑。
