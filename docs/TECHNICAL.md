## 1. 知识层：ClearChem-Qwen

### 1.1 底座

Qwen3.8-27B，约 27B 参数（64 层 / hidden 5120 / vocab 248,320），bf16 权重 54 GB。

### 1.2 训练配方

三批数据混合，单轮 LoRA 微调：

| 数据 | 条数 | 来源 | 标签质量 |
|---|---|---|---|
| 偏好靶向 | 4,275 | MolSkill 去重后的真实药化学家标注 | 人工标注 |
| 偏好蒸馏 | 38,837 | 自训 RankNet（留出集 0.677）标注 PubChem 分子对 | 约 2/3 正确 |
| RDKit 成对比较 | 38,800 | "A 和 B 哪个分子量更大"等，RDKit 确定性计算 | 100% 正确 |

```
LoRA rank 16 / alpha 32 / 7 个投影层
MAXLEN 384  BATCH 8  ACCUM 4  EPOCHS 1  LR 5e-5
4×A800 DDP，2,788 步
```

**关键的去污染步骤**：MolSkill 公开的 5,276 对标注中，
**1,000 对就是 ChemBench 的 chemical_preference 题目本身**。
必须按无序对（`frozenset`）逐条剔除，剩 4,275 对才能用。
脚本中有断言保证零重合。

### 1.3 Python 工具执行

数值题（243 道，占基准 8.7%）改为让模型写 Python 代码并执行：

```
提示   "Write a short Python program that computes the answer and prints ONLY the final number.
        You may use rdkit, math, itertools, sympy."
执行   子进程 + 20 秒超时 + 临时目录 + 空环境
兜底   代码跑不出（语法错/超时/缺库）则退回直答，因此不会亏
```

实测：修好 50 道、弄坏 6 道、43 道退回直答。数值题 0.4362 → 0.6214。

**浮点陷阱**：官方判定是 `abs(found - expected) == 0` 严格相等，
工具算出 `-0.6000000000000005` 会被判错。输出需规整到 12 位有效数字。
此问题曾使成绩虚高 0.25pp。

### 1.4 为什么不开思考模式

Qwen3.8 有原生 `<think>` 通道，但实测开启后 **0.5260，比关闭低 7.0pp（p=3e-24）**。
模型的"思考"是 `"We need answer... Need analyze... maybe?"` 这类自言自语，
不是结构化推理，对化学知识题反而把第一直觉里正确的答案推翻了。

用 2 万条真 R1 推理链训练也无效（p=0.07）。

## 2. 分子层

### 2.1 条件生成器

底座 ether0（Apache 2.0），LoRA rank 32 / alpha 64，条件通过 **embedding 注入**：

```
性质向量(5) + 缺失掩码(5) → 2层MLP → 8 个前缀 token embedding → 与文本 embedding 拼接
条件 MLP 是新参数，学习率 5e-4（LoRA 的 1e-5 的 50 倍）
末层近零初始化，让前缀起始时不干扰生成
```

**MLP_LR 必须是 5e-4**。降到 2e-4 会让 loss 从 step 750 起持续回升——
条件 MLP 近零初始化，学太慢会让前缀长期是"缓慢漂移的无效信号"，LoRA 追移动靶。

**训练步数：8,000 步最优。** 16,000 步过拟合（训练 loss 最低但评测全面最差），
3,000 步不足。**早停必须按真实评测的 MAE，不能按训练 loss**——两者在这里是反向的。

### 2.2 分区自适应拒绝采样

这是把 MAE 从 0.973 压到 0.109 的关键，**纯推理侧，不重训**：

```
K = K_条件数 × K_稀有度

K_条件数    单条件 8 · 双条件 16 · 三条件 32
K_稀有度    gap ≤8.5 → 1.0 ·  ≤10 → 1.25 ·  ≤11.5 → 1.75 ·  >11.5 → 2.5
温度        1.2（单条件）~ 1.4（三条件），高温增加多样性靠筛选兜底

流程        生成 n×K 个 → 去重 → 五性质打分 → 按归一化误差排序 → 取前 n
```

**为什么 K 要按稀有度放大**：训练分布中 gap 中位数 7.0、p95 为 11.25，
高 gap 分子稀有，固定 K 捞不到足够候选。实测 gap=11.0 时 K=8 给 ±0.536，K=14 给 ±0.306。

**副作用是正向的**：Novelty 从 0.533 升到 0.928，SA 从 3.51 降到 3.40。
过采样 + 筛选让三个互相拉扯的指标同时改善。

### 2.3 性质打分器

```
特征   Morgan 指纹(半径2, 2048位) + 13 个 RDKit 描述符
模型   2061 → 1024 → 512 → 256 → 1，GELU + Dropout 0.1
训练   OneCycleLR, max_lr 3e-4, 30 epoch, smooth_l1
切分   Murcko 骨架切分，训练/验证/测试骨架完全不重叠
```

**必须按骨架切分**。同骨架分子性质高度相关，随机切会泄漏。

## 3. 配方层

### 3.1 电导率打分器

```
特征   38 种溶剂的归一化比例 + 盐 one-hot(14) + 比例基准 one-hot(3) + 浓度 + T + 1000/T
标签   log(k)，电导率跨两个数量级
切分   按文献 doi，同一篇整块进同一侧
```

**必须按 doi 切分**，且**必须报交叉验证**。见 [BENCHMARKS.md](BENCHMARKS.md) 第 3 节。

### 3.2 配方推荐：为什么不训生成模型

配方空间低维且结构化（14 盐 × 38 溶剂比例 × 浓度 × 温度），
且有 13,270 条真实配方作为种子。做法是：

```
从真实配方采样 → 只扰动比例(×0.6~1.6)和浓度(×0.7~1.4) → 打分 → 去重排序
```

**不造新的溶剂组合。** 生成模型会产出"五种溶剂随机混"这种数值凑巧但化学不合理的配方，
而从真实配方扰动天然保住了合理性。实测返回的都是 `LiPF6 + EC/DMC` 这类商用体系。

### 4.2 评测纪律

1. **任何自研评测工具，用之前先量它自己的误差**，并与待测量级对比。
   尺子误差 > 待测差异时，所有结论无效。
2. **报提升前先做配对 McNemar**，不看准确率差值。
3. **先算最小可分辨差** MDE ≈ 1.96·√(n_discordant)/n_total。
   低于此幅度的改动永远测不出来。
4. **分组数 < 30 时报 K 折交叉验证的均值±方差**，不报单次切分。
5. **新评测协议必须先复现旧协议**，写成断言。
   （曾因漏 `apply_chat_template` 使成绩从 0.5964 掉到 0.1174 而险些误判）
